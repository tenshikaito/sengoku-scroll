## 1. 角色选择画面

立志传模式下，确认剧本后进入此画面选择扮演的角色。

### 1.1 画面布局

```
┌──────────────────────┬──────────────────────────────────┐
│                      │ 姓名    出身  职位    武  智  政 │
│   角色肖像           │──────────────────────────────────│
│                      │ 织田信长 尾张  大名    85  90  82│
│   ──────────         │ 羽柴秀吉 尾张  足轻头  70  95  88│ ← 选中
│   羽柴秀吉           │ 前田利家 尾张  侍大将  82  65  60│
│   出身：尾张         │ 柴田胜家 尾张  军团长  90  55  48│
│   职位：足轻头       │ 丹羽长秀 尾张  奉行    60  78  85│
│   武70 智95 政88     │                                  │
│   魅80               │                                  │
│   技能：筑城★★★     │                                  │
│         辩才★★      │                                  │
│   特性：机略/忍辱    │                                  │
├──────────────────────┴──────────────────────────────────┤
│                                                          │
│        [ 返 回 ]                  [ 开始游戏 ]          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

> 左侧角色详细信息：小屏隐藏

### 1.2 交互说明

| 元素 | 操作 | 效果 |
|------|------|------|
| 返回 | 点击 | 返回剧本选择画面 |
| 角色表格行 | 点击 | 选中该角色，左侧显示角色详细信息 |
| 左侧角色信息 | — | 响应式显示，屏幕较小时隐藏 |
| 开始游戏 | 点击 | 以选中角色开始立志传模式。未选择时灰显 |

**设计说明**：
- 角色列表以**表格形式**显示，列：姓名、出身、职位、武、智、政
- 点击表格行选中角色，左侧显示详细基本信息（肖像/能力/技能/特性）
- 左侧信息区域响应式：大屏显示，小屏隐藏，只显示表格中的简要信息
- 只能选择1个角色

## 2. RPG主地图差异

立志传模式与大战略模式共享主地图框架，但有以下差异：

| 维度 | 立志传模式 | 大战略模式 |
|------|----------|----------|
| 视角 | 角色周围局部 | 全国全图 |
| 操作对象 | 角色+随从 | 势力/多单位 |
| 时间控制 | 实时+暂停 | 半回合制 |
| 信息密度 | 角色相关情报 | 势力全局情报 |
| 势力概要 | 不显示 | 显示 |
| 事件通知 | 角色相关事件 | 势力相关事件 |
| 右上角按钮 | [地图][系统] | [地图][情报][系统] |

### 2.1 RPG主地图布局

```
┌──────────────────────────────────────────────────────────┐
│ ⏸▶ 天正2年3月15日 黎明           缩略图 □视野 [地图][系统]│
│ 🎭 羽柴秀吉 足轻头 / HP 80/100 / AP 6/10                 │
│──────────────────────────────────────────────────────────│
│ 📋 发现商队 / 🗡 遭遇山贼                                │
│──────────────────────────────────────────────────────────│
│                                                          │
│                                                          │
│                   角色周围局部地图                        │
│                  （可缩放/拖拽/点击）                      │
│                                                          │
│                                                          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 2.2 时间控制

RPG模式的时间控制简化为暂停/继续和速度调节：

| 按钮 | 效果 |
|------|------|
| ⏸ | 暂停/继续 |
| ▶ | 1倍速推进 |

## 3. 角色面板

角色面板是RPG模式的核心UI，始终显示在主地图左侧：

```
┌────────────────────┐
│ 🎭 织田信长        │
│ 武士 / 足轻组头    │
│────────────────────│
│ HP  80/100        │
│ AP   6/10         │
│────────────────────│
│ 武:72 智:65 政:58 │
│ 魅:80 统:68       │
│────────────────────│
│ 🗡 前田利家       │
│ 🏹 佐佐成政       │
│────────────────────│
│ 📍 清洲城 / 道场  │
└────────────────────┘
```

| 元素 | 操作 | 效果 |
|------|------|------|
| 角色名 | 点击 | 打开角色情报详情 |
| HP/AP | — | 实时显示当前值 |
| 随从名 | 点击 | 打开随从情报详情 |
| 位置 | 点击 | 定位到角色所在位置 |

## 5. RPG战斗触发

RPG模式中，角色遭遇战斗时弹出遭遇画面：

**遭遇战斗：**

```
┌──────────────────────────────────────────┐
│             ⚔ 遭遇战斗                  │
│──────────────────────────────────────────│
│ 敌方：山贼团 5人 / 头目：山贼头 武:55   │
│ 己方：羽柴秀吉 + 随从2人                │
│──────────────────────────────────────────│
│                                          │
│        ⚔ 进入战斗    🏃 逃跑            │
│                                          │
└──────────────────────────────────────────┘
```

**设计说明**：
- RPG模式中战斗始终进入战术地图，无瞬间事件结算
- 玩家直接操控角色和随从
- 逃跑有概率失败
