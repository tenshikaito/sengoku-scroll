## 0. 与策略模式的关系

> **开发顺序**：策略单机（M3）→ **RPG** → 策略多人联机 → MMO。RPG 在 **策略模式已可玩** 之后启动。

立志传（RPG）在工程与玩法上 **以策略单机为基线**，不是独立重写一套世界引擎。玩家在策略模式中已存在的 **地图、据点、单位、外交与经济骨架** 上，主要增加下列增量：

| 增量维度 | 策略模式（基线） | RPG 模式（增量） |
|----------|------------------|------------------|
| **世界时间推进** | 半回合制，按 **天** 推进，集体暂停/继续 | **时段（DayPhase）** 推进，可暂停 **实时** 流；角色 AP 驱动行动 |
| **场景结构** | 全国 **战略地图** + Popup 指令/情报 | 战略地图（局部视角）+ **据点内场景切换**（设施、NPC、商店等） |
| **内容与演出** | 系统/AI 驱动，无角色主线 | **大量剧情演出**（对话、分支、事件、任务线、随机事件） |
| **战斗** | 瞬间事件结算（策略单机） | **战术地图** 由 RPG 阶段 **首次实装** |
| **控制对象** | 势力 / 多单位 | 单角色 + 随从 |

**共用部分**（RPG 不重写）：`Character` / `Stronghold` / `Unit` / `Force` 实体，基础移动与外交规则，存档与事件框架，`GameDate` 类型（切换推进粒度与 System 组合即可）。

**实装策略**：优先扩展 `SengokuScroll.Rpg` 中的 `RpgTimeSystem`、场景状态机、事件/剧情管线；Domain 层仅增加 RPG 专属 Evaluator/Action。

## 1. 核心体验

参照太阁立志传5，玩家操控一个角色+随从小队，体验战国人生：

- 从足轻组头起步，通过任务/战斗/交际晋升
- 自由选择职业方向（武士/忍者/商人/剑豪/茶人等）
- 随从系统：可招募随从，战斗时随从协同作战
- 个人成长：技能修炼、卡片收集、人际关系

## 2. 系统架构

```
RpgGameEngine : GameEngineBase
├── RpgCharacterSystem      角色系统（核心）
│   ├── 个人行动处理
│   ├── 随从管理
│   └── 人际关系更新
├── RpgTimeSystem           时间系统
│   ├── 时段推进
│   └── 日/月/年事件触发
├── RpgEventSystem          事件系统
│   ├── 随机事件触发
│   ├── 剧情事件推进
│   └── NPC行为事件
├── RpgGrowthSystem         成长系统
│   ├── 技能经验累积
│   ├── 能力值成长
│   └── 称号/名声更新
└── RpgAISystem             AI系统
    ├── NPC日常行为
    ├── NPC决策
    └── NPC对玩家态度变化
```

## 3. 角色行动体系

```
RpgCharacterAction（角色行动）
├── 移动类
│   ├── 移动到据点        消耗AP按距离
│   ├── 进入据点设施      消耗5AP
│   └── 离开据点          消耗3AP
├── 交互类
│   ├── 与NPC对话         消耗1AP
│   ├── 赠送礼物          消耗1AP+金钱
│   ├── 拜师学艺          消耗2AP
│   └── 交际宴会          消耗2AP+金钱
├── 修炼类
│   ├── 个人修炼          消耗4AP，提升技能经验
│   ├── 师范修炼          消耗3AP，有师父加成
│   └── 实战修炼          消耗4AP，战斗中学习
├── 任务类
│   ├── 接受任务          消耗1AP
│   ├── 执行任务          消耗全AP
│   └── 报告任务          消耗1AP
├── 战斗类
│   ├── 个人决斗          进入战术地图
│   ├── 随从战斗          进入战术地图（带随从）
│   └── 参与合战          进入战术地图（大规模）
└── 生活类
    ├── 休息              恢复HP/AP
    ├── 购物              买卖物品
    └── 治疗              消耗金钱恢复
```

## 4. 随从系统

```
FollowerSystem
├── 招募
│   ├── 对话招募（好感度达标）
│   ├── 金钱雇佣
│   └── 事件获得
├── 管理
│   ├── 随从上限 = 魅力/10 + 声望/50 + 职位加成
│   ├── 随从忠诚度（影响叛逃概率）
│   └── 随从薪酬（每月支出）
├── 战斗
│   ├── 随从在战术地图中作为独立单位
│   ├── 随从受玩家指令控制
│   └── 随从阵亡=永久失去（或重伤恢复）
└── 成长
    ├── 随从跟随战斗获得经验
    ├── 随从可独立修炼
    └── 随从可晋升为正式家臣
```

## 5. 游戏循环

```
RpgGameLoop : GameLoopBase
├── 推进方式：实时 + 可暂停
├── 每时段（DayPhase）执行：
│   ├── 1. 处理玩家行动（如果AP足够）
│   ├── 2. 处理随从行动
│   ├── 3. 处理NPC行动
│   ├── 4. 触发随机事件
│   ├── 5. 更新角色状态（AP恢复、HP恢复等）
│   └── 6. 检查日/月/年事件
├── 暂停条件：
│   ├── 玩家手动暂停
│   ├── 事件触发时自动暂停
│   └── 进入战斗时暂停大地图
└── AP系统：
    ├── 每时段恢复 NextTurnApRecovery 点
    ├── 不同行动消耗不同AP
    └── AP耗尽自动进入休息
```

## 6. 职业系统

```
RpgProfession（职业）
├── 武士       主线职业，可晋升为城主/大名
├── 忍者       情报/暗杀/破坏
├── 商人       交易/投资/赚钱
├── 剑豪       武道修行/道场经营
├── 茶人       茶道/文化/外交
├── 海贼       海上贸易/掠夺
├── 医师       治疗/炼药
└── 铸匠       锻造武器/防具
```

每个职业有专属的：
- 技能树
- 卡片集
- 任务线
- 晋升路径

## 8. RPG专属UI

立志传模式的 UI 设计以角色为中心，与大战略模式共享主地图框架但交互方式不同。完整界面规格见 **[立志传模式界面设计](./rpg-ui-design.md)**。

### 8.1 角色选择画面

详见 [立志传模式界面设计 §1](./rpg-ui-design.md#1-角色选择画面)。

### 8.2 主地图差异

| 维度 | 立志传模式 | 大战略模式 |
|------|----------|----------|
| 视角 | 角色周围局部 | 全国全图 |
| 操作对象 | 角色+随从 | 势力/多单位 |
| 时间控制 | 实时+暂停 | 半回合制 |
| 信息密度 | 角色相关情报 | 势力全局情报 |

### 8.3 角色面板

角色面板是RPG模式的核心UI，始终显示在主地图上：

```
┌──────────────────────────┐
│  🎭 织田信长              │

│  HP ████████░░ 80/100     │
│  AP ██████░░░░ 6/10       │
│  ─── 能力 ───             │
│  武:72 智:65 政:58        │
│  魅:80 统:68              │
│  ─── 随从 ───             │

│  ─── 位置 ───             │
│  📍 清洲城 │ 道场          │

```
