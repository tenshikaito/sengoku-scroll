# 发布前四项修复验收 — 2026-09-05

本轮完成上一轮审计确认的四项修复；仅在本地修改、构建和验证，未提交、推送 Git、打远程标签或公网部署。

## 修复内容

1. **损坏 v2 存档拒绝加载**：完整运行时缺失或解析失败时抛出明确异常，由主机事务式恢复保留原世界；不再降级到旧版局部字段恢复。真正的 v1 存档仍兼容。房间启动跳过损坏世界并保留原快照。
2. **继位后的当主解析统一**：先查有效运行时注册表，再查 `Force.LordCharacterId`，最后兼容剧本元数据；候选必须存活且属于该势力。不带注册表的视野、路由和显示调用因此能获取继承者。
3. **投递失败与成功收件隔离**：失败使用 `ReportDeliveryFailed` 通用提醒，不含战斗对象、报告详情或敌方名称。失败去重键使用独立命名空间，随现有运行时服务状态保存，不消费成功收件键。以后收到同一报告时仍正常显示，成功重复投递仍被去重。未新增自动重派队列。
4. **跨读档稳定顺序**：运输队和信使按实体 ID 遍历；税务台账快照明确排序；完整世界捕获采用按 ID 排序的实体表副本，不重排正在运行的世界字典。单机、多人 60 天连续运行与 30 天存档/恢复后续玩 30 天的完整 JSON 逐字一致。
