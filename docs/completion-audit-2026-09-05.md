# 战国绘卷完成度审计（2026-09-05）

## 已完成的可玩闭环

- 开局：难度与规则选项、玩家模式、全势力 AI 观战模式、首次进入教学。
- 战略：日推进、移动、补给、野战、攻城、占领、战争分数、和谈与停战。
- 内政经济：税制、农业周期、市场价格、商队、关税、贡纳和 AI 月度政策。
- 情报：地图雾区、势力视野、谍报精度与过期、行情时效；谍报台账按观察势力隔离。
- 角色：任职、关系/信任/情绪、交谈、赠礼，以及婚姻/仕官/名声/统一目标进度。
- 持久化：V2 存档保存动态实体、战争、市场、外交、运行时台账、角色钱/行动力/生命/情绪，并兼容旧存档。
- 前端：统一进度、观战态势、角色互动、教学、批量推进和新首页原型美术。

## 可靠性与性能

- 全套测试 394/394 通过（Application 1、Strategy 377、Web API 16），解决方案构建为 0 警告、0 错误。
- 仿真随机改为固定种子与稳定哈希，避免 `.NET HashCode` 进程盐导致跨进程回放漂移。
- 全势力视野快照在 4 个以上势力且多核可用时并行计算，世界状态仍按固定顺序提交。
- AI 敌情按势力去重并行计算；势力/据点/单位/人物 DTO 与大地图格数组达到阈值后并行映射。
- 人物目标的领地统计改为一次聚合，并可按人物并行刷新。
- 观战高速模式通过批量日推进减少 HTTP、JSON 和完整 DTO 重建次数。
- 365 日全势力 AI 长稳测试覆盖季节与年度结算，并验证核心资源与实体状态。
- 前端按 Vue、Element Plus、Pixi 和 ECharts 分块；生产依赖审计无已知漏洞。

## 仍需后续立项的范围

以下不是已知回归阻塞，而是还没有完整落地的设计范围：

1. 军事 AI 已按自己的视野筛选敌军，但据点位置作为公开战略地理；敌方据点的精确动态数值尚未做完整“AI 记忆/过期情报”模型。
2. 建设投资、灾年、掠夺、设施荒废、气候/天气与更细人口模型尚未实现。
3. 角色关系已有可玩入口，婚姻事件链、招募谈判、派系和通用可配置任务/奖励编辑器仍需扩展。
4. 目前只有 `mini_kanto`；需要更多剧本、地图、人物、美术和长期数值平衡样本。
5. 更高级攻城、分段伤亡、装备 MasterData、独立战术地图仍是下一阶段。
6. RPG 与 MMO/多人联机属于独立的大型阶段，不能视为当前单机策略原型的小补丁。

完整证据、设计冲突和部署门槛见 [全游戏审计](full-game-audit-2026-09-05.md)。
