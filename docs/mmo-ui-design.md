## 2. MMO主地图差异

MMO模式与大战略模式共享主地图框架，但有以下差异：

| 维度 | MMO模式 | 大战略模式 |
|------|---------|----------|
| 时间推进 | 服务器统一推进 | 玩家自行控制 |
| 时间控制 | 无暂停/加速按钮 | ⏸▶▶▶▶▶▶ |
| 势力概要 | 仅显示玩家所属势力 | 显示玩家势力 |
| 情报按钮 | 有 | 有 |
| 多人信息 | 显示其他玩家位置/活动 | 无 |
| 右上角按钮 | [地图][情报][社交][系统] | [地图][情报][系统] |
| 战斗方式 | 仅方针自动结算 | 可选亲自指挥 |

### 2.1 MMO主地图布局

```
┌──────────────────────────────────────────────────────────┐
│ 天正2年3月15日 黎明 / 织田家 / 据点:3 / 💰8,500         │
│                          缩略图 □视野 [地图][情报][社交][系统]│
│──────────────────────────────────────────────────────────│
│ ⚔ 今川军进攻 / 📨 信使到达 / 📋 月度结算                │
│ 👤 在线: 12人                                            │
│──────────────────────────────────────────────────────────│
│                                                          │
│                                                          │
│                   战略地图                                │
│            （显示其他玩家标记/活动）                       │
│                                                          │
│                                                          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**MMO特有元素**：
- 时间由服务器统一推进，无暂停/加速按钮
- 显示在线玩家数
- 地图上可看到其他玩家的位置标记（友方可见，敌方需谍报）
- 右上角增加 [社交] 按钮

## 3. 国战界面

国战是MMO模式的核心玩法，多个玩家势力之间的战争。

### 3.1 国战宣告

```
┌──────────────────────────────────────────────────────┐
│ 目标势力：[今川家 ▼]                                 │
│──────────────────────────────────────────────────────│
│ 战争理由：                                           │
│ ○ 领土纠纷   合法性+10%  副作用：—                 │
│ ○ 宿怨       合法性+5%   副作用：关系-20            │
│ ● 争霸       合法性+0%   副作用：声望-50            │
│ ○ 保护同盟   合法性+15%  副作用：需有同盟势力       │
│──────────────────────────────────────────────────────│
│ 预估：                                               │
│       据点    武将    兵力                            │
│ 己方    3      12    8,500                            │
│ 敌方    6      18   15,000（谍报估算）               │
│ 同盟支援：1势力可参战                                │
│──────────────────────────────────────────────────────│
│ ⚠ 国战宣告后24小时（现实时间）开始战斗              │
│ ⚠ 宣告期间其他玩家可加入任一方                      │
├──────────────────────────────────────────────────────┤
│            [ 宣告国战 ]          [ 返回 ]            │
└──────────────────────────────────────────────────────┘
```

### 3.2 国战准备期

宣告后进入24小时准备期，所有相关玩家可查看准备状态：

```
┌──────────────────────────────────────────────────────┐
│ 攻方（织田家）：                                     │
│ 玩家：PlayerA (大名)                                 │
│ 同盟参战：松平家(PlayerC)                            │
│ 参战兵力：8,200                                      │
│ 参战据点：清洲城 那古野城 末森城                     │
│──────────────────────────────────────────────────────│
│ 守方（今川家）：                                     │
│ 玩家：PlayerB (大名)                                 │
│ 同盟参战：北条家(AI)                                 │
│ 参战兵力：12,000（谍报估算）                         │
│ 参战据点：骏府城 挂川城 ...                          │
│──────────────────────────────────────────────────────│
│ 战斗开始：18小时32分后                               │
│──────────────────────────────────────────────────────│
│ 可执行操作：                                         │
│ · 调动部队到前线据点                                 │
│ · 请求同盟支援                                       │
│ · 派遣忍者侦察敌方部署                               │
│ · 设定参战单位方针                                   │
├──────────────────────────────────────────────────────┤
│          [ 查看地图 ]  [ 设定方针 ]  [ 返回 ]        │
└──────────────────────────────────────────────────────┘
```

### 3.3 国战结算

国战由服务器自动结算，结果广播给所有玩家：

**国战结果：**

```
┌──────────────────────────────────────────────────────┐
│ ⚔ 织田家 vs 今川家 — 尾张争夺战                     │

│──────────────────────────────────────────────────────│
│ 领土变更：                                           │
│ 织田家 → 获得：尾张城                               │
│ 今川家 → 失去：尾张城                               │
│──────────────────────────────────────────────────────│
│ 战损：                                               │
│       损失     残余                                  │
│ 攻方  2,100    6,100                                 │
│ 守方  5,400    6,600                                 │
│──────────────────────────────────────────────────────│
│ 战争分数：                                           │
│ 织田家：30    今川家：10                             │
│ （达成100分可要求议和条件）                           │
├──────────────────────────────────────────────────────┤
│                       [ 关 闭 ]                      │
└──────────────────────────────────────────────────────┘
```

## 5. MMO社交界面

从右上角 [社交] 按钮打开。

### 5.1 社交Tab

```
┌──────────────────────────────────────────────────────┐
│ [好友]  [势力]  [世界]                               │
│──────────────────────────────────────────────────────│
│ 好友列表：                                           │
│                                                      │
│ 🟢 PlayerB   今川家  大名      [密谈]               │
│ 🟢 PlayerC   松平家  家老      [密谈]               │
│ ⚪ PlayerD   斋藤家  奉行      [留言]               │
│ 🟢 PlayerE   织田家  侍大将    [密谈]               │
│──────────────────────────────────────────────────────│
│ 好友申请：PlayerF 请求添加好友  [接受] [拒绝]       │
│──────────────────────────────────────────────────────│
│ [________________________________________] [发送]    │
└──────────────────────────────────────────────────────┘
```

### 5.3 交互说明

| 元素 | 操作 | 效果 |
|------|------|------|
| 好友名 | 点击 | 查看好友角色信息 |
| 密谈 | 点击 | 打开与该玩家的私聊窗口 |
| 留言 | 点击 | 给离线玩家发送留言 |
| 接受/拒绝 | 点击 | 处理好友申请 |
| 聊天输入 | 输入+发送 | 发送聊天消息 |
