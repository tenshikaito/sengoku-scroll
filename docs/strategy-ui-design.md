```

│ 织田家 / 据点:3 / 武将:12 / 💰8,500 / 🌾12,000 │          │
│───────────────────────────────────────────────│   缩略图  │
│ ⚔ 今川军进攻 │                                 │          │
│ 📨 信使到达 │                                 │──────────│
│ 📋 月度结算 │                                             │
│─────────────│                                            │
│                                                          │
│                                                          │
│                     战略地图                              │
│                （可缩放/拖拽/点击）                        │
│                                                          │
│                                                          │
│ ──────────────────────────────────────────────────────── │
│ 当前所指地图块的地形   地图块上的据点   地图块上的单位       │

```

**大屏布局（≥768px）**：势力概要与时间控制同行显示
**小屏布局（<768px）**：势力概要换行显示

### 2.2 上部左侧 — 时间控制 + 势力概要 + 事件通知

| 元素 | 操作 | 效果 |
|------|------|------|
| ⏸ | 点击 | 暂停/继续（按钮状态切换，不显示文字） |
| ▶ | 点击 | 1倍速（按钮高亮表示当前速度） |
| ▶▶ | 点击 | 2倍速 |
| ▶▶▶ | 点击 | 4倍速 |
| 势力名 | 点击 | 打开情报系统→势力情报 |
| 据点数 | 点击 | 打开情报系统→据点列表 |
| 武将数 | 点击 | 打开情报系统→角色列表 |
| 💰 | 点击 | 打开情报系统→经济情报 |
| 🌾 | 点击 | 打开情报系统→经济情报 |
| 事件通知 | 点击 | 打开对应事件详情（信使报告/战报等） |

**设计说明**：
- 速度用按钮的高亮/按下状态表示当前速度，不显示"速度:2"文字
- 不显示月进度条（已有日期显示，无需重复）
- 势力概要紧贴时间控制下方，大屏时同行显示，小屏时换行
- 事件通知位于势力概要下方，由信使系统驱动，不会即时弹出
- **底部无时间控制**，时间控制仅在画面上部左侧

### 2.3 上部右侧 — 小地图 + 功能按钮

| 元素 | 操作 | 效果 |
|------|------|------|
| 地图 | 点击 | 弹出地图窗口（详见第3章） |
| 情报 | 点击 | 打开情报系统（详见第9章） |
| 系统 | 点击 | 打开系统菜单 |
| 小地图 | 点击 | 快速跳转视野到点击位置 |

**设计说明**：
- 小地图只显示预设地图缩略图（地形/河流/山脉），**不显示势力颜色**
- 势力颜色在大地图中显示
- 方框标注当前视野范围

### 2.4 M3-b 纵切实装布局（WebClient · mini_kanto）

当前 `Strategy.vue` 纵切与上文 §2.1 长线目标略有差异，**以本节为准**直至 M4 统一顶栏/事件区。

**布局原则**：顶栏/底栏均为 **地图 overlay 悬浮条**（四周留白、圆角半透明背景）；**消息简报区无背景**，叠在地图左上；地图画布占满 `map-column` 全高。

```
┌──────────────────────────────────────────────────────────┐
│ [地图名]                              [推进/存档/读档…]  │ ← 页面顶栏（非地图内）
├──────────────────────────────────────────────────────────┤
│  ┌─ 地图 overlay（上）──────────────────┐ ┌──────────┐ │
│  │ 📋消息 [全部|我方|世界]              │ │ 日期     │ │
│  │ （8行简报·透明 textarea·不可点）     │ │ 势力💰🌾 │ │ ← 右侧为悬浮状态条
│  └─────────────────────────────────────┘ └──────────┘ │
│                                                          │
│                     PixiJS 战略地图                       │
│              单位 / 据点 / 运输队🌾 / 信使📨              │
│                                                          │
│  ┌─ 地图 overlay（下）────────────────────────────────┐ │
│  │                          [📨][💰]… 通知图标 RTL   │ │
│  │ ┌ 格点情报摘要（悬浮）────────────┐ ┌地图视图┐    │ │
│  │ │ 🏯据点 · ⚔部队 · 🌾运输队 …   │ │势力/封地│    │ │
│  │ └───────────────────────────────┘ └────────┘    │ │
│  └──────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

| 区域 | 行为 |
|------|------|
| **消息区（左上）** | 按钮 + 筛选 checkbox 与 **8 行简报同一区域**；简报 **透明**、固定 8 行、无滚动、不可点击；超出从头部丢弃 |
| **消息筛选** | **全部**：仅同步勾选「我方消息 + 世界消息」（半选态）；**我方 / 世界**：实际筛选开关，可独立切换 |
| **打开消息对话框** | 仅 **📋 消息** 按钮；对话框内容随当前筛选 |
| **日期/势力/资源** | 地图 **右上悬浮条**（有背景），与消息区同一 overlay 行 |
| **通知图标** | 地图 **右下 overlay 上排**，自右向左；点击打开收支结算 / 战报等（**不**随日推进自动弹收支窗） |
| **底栏情报** | 悬停地图格时显示：`地形 · 政治区域`；`🏯 据点 · 势力`；`📍 地标`（**独立段**，不与据点拼接）；不显示单位/运输队/信使；鼠标离开地图 **隐藏** 底栏 |
| **地图地标** | 格内 ◆ 金色标记（`map.landmarks[]`）；与 playable 据点 **数据分离**（见 [详细设计 §5 地标](./strategy-detail-design.md)） |
| **地图视图** | 与底栏情报 **底对齐**、独立高度；势力 / 封地 / 外交 三档 |
| **格点悬停情报** | 同格 **据点框 + 其他实体框横向并排**；`fixed` 定位可超出地图；运输队悬浮仅：势力/总将/兵数/士气/粮草 |
| **指令 Popup** | 己方单位：移动/攻击/方针/情报；**不在 Popup 上显示 AP 不足等禁用原因** |
| **AP 不足** | 攻击按钮 **不禁用**；点击后 **对话框** 说明 + 写入页面信息栏 |
| **势力/封地/外交着色** | 势力：每势力（含内藩）独立色；封地：内藩与宗主同色；外交：蓝自/绿盟/红敌/橘中立 |
| **运输队** | 可点击指令菜单（情报）；移动系统自动调度 |

## 6. 单位情报悬浮与详情

### 6.1 悬浮情报框

**M3-c 实装**：**运输队**与 **信使**（均 `IsMilitary=false`）悬浮/详情字段与军事单位 **同结构**；运输队含总将，信使为 **NPC 传令兵+护卫**、无总将。底栏摘要见各实体类型。

**M3-c 悬浮布局**：同格同时存在 **据点** 与 **其他实体**（单位/运输队/信使）时，两框 **横向并排**（据点靠格、其他向外）；仅单类实体时单框。锚定侧由视口 slack 评分选择（左/右/上/下）；左右锚定时 **底边对齐**。完整数值进详情对话框。

**运输队悬浮（M3-d+）**：仅 势力 / 总将 / 兵数 / 士气 / 粮草；不含训练度、文化、信仰、任务、方针。

```
        └────────────────┘  │ 运输队 …       │
                              └────────────────┘
```

## 13. 信使系统

> **M3 实装范围**（2026-07-09 更新）：信使为 **地图实体**，由系统 **自动派遣**；玩家 **不** 手动点选信使路线。  
> **同格规则**：当主与目标单位 **在同一格**（含同在据点内）→ 方针 **立即生效**，无需信使。  
> **异格规则**：方针变更、战报 → 自动生成信使；**到达当主所在格后** 在左上消息区可见摘要。  
> **战报信使**：自 **己方参战部队所在格** 出发，向当主回程；**战斗当日不移动**，次日随信使系统出发。  
> **运输粮草** 由 **运输队** 负责（卸粮后 **返程** 至出发据点）；玩家可打开运输队 **指令菜单** 查看情报，改道经信使（后续 API）。  
> 实装细则见 [策略开发计划 §6.2–§6.3](./strategy-development-plan.md#62-方针间接指挥与信使制度strategymessengersystem)。

信使系统负责 **信息传递与远程指令下达**；与 **运输队后勤** 分工明确。

|----|------|
| 顶/底栏 | 绝对定位 overlay，`padding` 留白，圆角 + 半透明背景（消息正文除外） |
| 底栏情报 | `地形 · 区域`；`🏯 据点 · 势力`；`📍 地标`（各为独立 segment，不用「·」连接据点与地标）；无占位文案；仅 **鼠标在地图格上** 时显示 |
| 地标地图标记 | 格内 ◆（`mapLayer`）；数据来自 `map.landmarks`，非 `strongholds` |
| 坐标源（底栏） | **仅** 当前鼠标悬停格（不用选中格/固定悬浮格） |

### 14.4 错误与反馈

| 场景 | 反馈 |
|------|------|
| AP 不足无法攻击 | **对话框** + 信息栏；**不在** 指令 Popup 上显示 |
| WebApi 未加载剧本 | 客户端自动 `POST /load` 重试；仍失败则提示刷新 |
| 方针异格 | 信息栏 + 左上消息；当主 **所在格** 为信使出发点 |
