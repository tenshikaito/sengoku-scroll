# 人物社会玩法首版 — 2026-09-05

历史版本说明：2026-09-06 的 [人物决策首批](character-agency-implementation-2026-09-06.md) 已替换本文社交排序、婚约 AI、每周忠诚与叛离意向的固定门槛；冷却、成年/近亲限制、真人同意、个人投奔的执行约束继续保留。

本轮将社交冷却、有限事件记忆、关系驱动 NPC 行为、个人叛离与婚约接入游戏。它是可运行首版，不是完整家族/政治模拟。

## 1. 社交

- Talk：同一对人物每游戏日一次，双方共用冷却，不能反向绕过；1 AP。
- Gift：金钱礼物 100 文、2 AP；同一对人物间隔 7 日。当前不是库存物品送礼。
- 物欲影响收礼人的关系收益；基线亲疏达到 75 后收益降为 +1。仍保留仇敌减益、魅力修正。
- 失败检查在扣款/AP 前完成，收款溢出也拒绝；被俘不能操作。
- 冷却字段存于方向性关系记录并随完整 v2 世界保存，不依赖记忆列表。

## 2. 事件记忆与可见性

每人物保留最近 64 条，人物内 Id 单调递增。记录实际发生的交谈、赠礼、婚约提出/收到/拒绝/到期/结婚、忠诚变化、叛离预警/取消/投奔；不是虚构历史 seed。

记忆是审计记录，关系变化已在事件发生时写入，显示记忆不会再次叠加。淘汰历史不会重置冷却。当前尚未接管全部战斗、赏罚和杀亲事件。

人物详情展示真实记忆、婚约按钮和叛离预警。新增记忆、待处理婚约、预警日只向本势力 DTO 输出；不是对旧版所有关系字段可见性做了全面重构。

## 3. 关系驱动 NPC

- 每人物每游戏日最多结算一次；固定按 Id 遍历，检查日也保存在人物上。
- 按人物 Id 分散到每周一天，健康空闲 NPC 优先与同势力同地点、关系较好的人交谈；目标排序使用亲疏加半数信任，再按 Id 打破平局。
- NPC 对当主亲疏 ≥50，每周忠诚 +1；≤−50，每周 −2，其他区间不变。
- 不替真人当主花费社交 AP 或接受婚约；联机模式当主即使离线也不由本系统代为同意婚约（全 AI 观战除外）。
- 不影响原任务优先权：被俘、生病、有募兵/使节任务者不执行这些自主互动。

## 4. 婚姻（婚约—回应—配偶）

人物页“提出婚约/同意婚约”复用权威互动接口，消耗 2 AP；拒绝不收费。双方必须同地点、存活、年满 18 岁、没有在世配偶、不是父母/祖父母/兄弟姐妹或共享两代内祖先的近亲；被俘不可操作。

婚约有效 30 日，同一对象提议冷却 30 日；目标一次仅保留一个有效待处理提议。接受是对反向提议的明确回应，原子更新双方 SpouseId 并增加关系/信任。NPC 仅在同地点、条件有效、对提议者亲疏 ≥50、信任 ≥25、有 AP 时同意；负面亲疏或不合资格会拒绝，其余等待/到期。

当前使用通用成年配偶规则，不限制性别；没有声称模拟历史婚制。未知亲属关系无法凭空推断；仅按录入的父母图检查。已故配偶不阻止再婚。

不自动结盟、不转移势力或领地、不生育、不安排继承顺位；没有离婚/家族包办、婚礼资源流程或 NPC 自主择偶提案。这些均是后续系统，不能把本轮婚约首版当成王朝模拟。

## 5. 叛变首版：个人叛离/投奔

不是随机叛乱，也不创建新势力。条件：非当主、野心 ≥70、有效忠诚 ≤20、对本家当主亲疏 ≤−60，先向本势力发出预警并记忆；连续维持条件至少 30 日。

执行时还必须：空闲健康、无任务、无职位和直属上司、不是当主/继承人/据点长官/军事主将或子编制将领，也不在据点 Actor 人员表中；已经身处另一势力据点，并对其当主亲疏 ≥50。满足才更新个人归属、入仕日期、忠诚和空闲行动状态，分别私信通知离开/加入势力。

不会自动带走军队、城池、公共金库，也没有为了触发叛变而瞬移或自动远赴他家。改善关系或忠诚使条件不再成立，会取消预警。现阶段有职位/部队绑定的人不迁移，避免产生悬空归属。
