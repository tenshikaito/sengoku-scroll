## 1. 设计原则

1. **指令与情报分离**：所有指令和情报各自独立为系统，不在详情画面中混杂
2. **RPG 以策略为基线**：立志传模式在策略单机之上增量改造——**时间推进形式**（时段/实时）、**据点内场景**、**剧情演出**；共用 Domain 与世界地图（见 [rpg-detail-design §0](./rpg-detail-design.md#0-与策略模式的关系)）
3. **决策优先、减少微操**（全局最高约束）：方便玩家进行战略/角色决策；**运输队与信使由系统自动派遣**（地图可见实体），玩家做战略取舍，**不要求**手动操控运输队或逐支派遣信使
4. **间接指挥**：NPC 统帅的单位通过 **方针与战略目标** 间接控制，不可逐格微操；玩家直属单位同格可下直接指令，异格经信使
5. **信使制度**：战报、外交、**远程方针/战略指令** 均经信使传递；**同格（含同在据点内）免信使**；截获/篡改为 M4 可选高级机制；**粮草仅由运输队运送**
6. **统帅+军师**：单位核心由统帅（决定军队属性）和军师（决定计谋攻防）两人决定
7. **交互分层**：鼠标悬停显示情报，左键弹出指令菜单；触屏第一次单击显示情报，第二次单击弹出指令菜单
8. **单机战斗可选模式**：瞬间（自动）战斗（M3 实装）或亲自指挥（战术地图，**后期开发**）；多人仅瞬间战斗
9. **合理默认与预览**：未设方针使用势力默认；开战等高风险操作须先显示胜率/后果预览

## 2. 画面总览与导航关系

```
主菜单
├── 新游戏 → 剧本选择画面
│   ├── 立志传模式 → 角色选择画面 → 主地图
│   └── 大战略模式 → 势力选择画面 → 主地图
├── 继续游戏 → 存档选择画面 → 主地图
└── 多人游戏 → 多人大厅 → 主地图

主地图（核心画面）
├── 上部左侧：时间控制 + 势力概要
├── 上部右侧：小地图 + [地图][情报][系统]按钮
│
├── 鼠标悬停/触屏第一次单击 → 情报悬浮框
├── 鼠标左键/触屏第二次单击 → Popup指令菜单
│
├── 信使到达时 → 弹出信使报告
└── 战斗触发时
    ├── 单人模式 → 可选择进入战术地图亲自参战
    └── 多人模式 → 瞬间事件预览 → 自动结算
```

## 7. 交互分层规则

### 7.1 鼠标操作

| 操作 | 效果 |
|------|------|
| 鼠标悬停 己方据点/单位/角色 | 显示情报悬浮框 |
| 鼠标悬停 敌方目标 | 显示情报悬浮框（精度取决于谍报） |
| 左键单击 据点/单位/角色 | 弹出Popup指令菜单 |
| 左键单击 空地 | 取消选中，关闭菜单和悬浮框 |
| 拖拽空白 | 平移地图 |
| 滚轮 | 缩放地图 |

### 7.2 触屏操作

| 操作 | 效果 |
|------|------|
| 第一次单击 据点/单位/角色 | 显示情报悬浮框 |
| 第二次单击 同一目标 | 弹出Popup指令菜单 |
| 单击 空地 | 取消选中，关闭菜单和悬浮框 |
| 单指拖拽空白 | 平移地图 |
| 双指缩放 | 缩放地图 |

**设计说明**：
- 鼠标模式：悬停=情报，左键=指令（信息获取和操作分离）
- 触屏模式：第一次单击=情报，第二次单击=指令
- 两种模式都遵循"先看情报，再下指令"的逻辑

## 9. 响应式断点

> **目标平台**：PC 与平板（大屏设备）。下列断点以桌面/平板布局为主；触屏规则适用于平板触屏操作。手机非目标平台。

| 断点 | 屏幕宽度 | 隐藏/变化元素 |
|------|----------|----------|
| 大屏（PC） | ≥1200px | 全部显示，势力概要与时间控制同行 |
| 中屏（平板） | 768~1199px | 剧本插图缩小，角色详情简化，势力概要换行 |
| 小屏 | <768px | 剧本插图隐藏、剧本说明隐藏、角色详情隐藏、势力概要换行（供平板竖屏参考） |
