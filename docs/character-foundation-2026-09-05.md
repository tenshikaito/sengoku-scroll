# 人物基础系统第一批修复 — 2026-09-05

本轮落实概念统一、剧本配置、关系显示和效果到期；不是完整社交/派系系统上线。

## 规则

- Action 统一为慎重：0 轻率，100 慎重；保留旧字段和旧存档数值，不翻转。战后逃脱公式的此参数解释为胜方围捕慎密程度，公式不变。
- Friendship 是重义倾向，Character.Loyalty 是对势力忠诚，CharacterRelationship 是 A→B 私人关系，三者独立。
- 关系 DTO 及亲疏标签采用有效值：基线加未到期对应 ViewEffects，钳制 −100～100。PersonalOpinion 不自动折算亲疏；旧私人 Diplomacy 类型兼容折算亲疏。存档仍保存基线，不重复累计。
- 分档：≥75 亲密，≥25 友好，>−25 普通，>−75 险恶，其余仇视。方向独立。
- 仇敌是身份记录，不覆盖当前亲疏。有数值关系但无身份的人加入“相识”；增加反向“弟子”。
- Temporary 在到期日当天日初删除，覆盖人物/据点/势力影响及私人/外交看法。缺少到期日视为无效；Permanent/LongTerm 不按日期删除。关系、忠诚有效值查询也过滤到期条目。

## 数据与兼容

剧本 Personality 十项可配置，缺省 50，范围 0–100，越界拒绝。mini_kanto 为 11 名具名人物配置差异，其余角色仍默认中性。

**人物数值是游戏平衡设定，不是历史心理事实。** 完整 v2 旧存档继续使用保存的性格，体验新配置需新开局。喜好五分类仍是推导展示，界面已标注，并未实现真实五类礼物偏好。

删除后端演示看法注入和前端四套历史看法回退；真实空数据返回空列表。旧存档已有演示条目不按名称自动删除，因为缺少来源标识，可能误删合法事件；此项需后续显式迁移。
