# 人物行为机制设计 v1（2026-09-06）

目标：角色在相同处境中因能力、价值取向、关系和经历不同作出不同选择；行为可解释、可回放，不靠全知或逐角色硬编码。本文是总体设计，实施状态以末节为准。

## 一、概念边界

| 层次 | 现有数据与职责 | 禁止混淆 |
| --- | --- | --- |
| 能力 | 统率、力量、政治、智谋、魅力及熟练度；决定观察判断质量和执行效果 | 高能力不是忠诚，也不是必然做出道德选择 |
| 性格 | Temper 温和、Courage 勇气、Principle 理想倾向、Action 慎重、Friendship 重义、Ambition 野心、Desire 物欲 | Friendship 不是对某人的好感；Action 越大越慎重；理想主义不是善恶值 |
| 状态 | Hp、疾病、Emotion、AP、金钱、职责与任务 | 心情不是永久性格；有意愿不等于有资源 |
| 关系 | A→B 亲疏、信任，势力忠诚；身份边另存 | 喜欢不等于信任；信任当主不等于认可其所有命令 |
| 记忆 | 实际事件、对象、日期、人物内序号 | 记忆展示不再次结算亲疏；未发生的事不可生成历史 |
| 目标 | 安全、职责、归属、地位、物质、承诺的竞争 | 动机分数不是行动成功率；目标不能绕过权限 |
| 认知 | 本人经历、本势力已知情报、可见局势 | 不读取敌人隐藏性格/金库作为个人择偶依据 |

Hobby 目前没有离散偏好内容，Drinking 不承担社交积极性代理，Fortune 不承担道德/能力代理；三者在缺少对应规则时不硬塞进所有公式。文化、性别、出身不直接推导能力或品德。

## 二、共同决策协议

1. **硬条件**：存活、身份、位置、成年与亲属限制、AP/钱、冷却、已有任务、玩家控制、命令约束。不合资格的行动不参与竞争。
2. **可知快照**：只提取评分所需的标量，禁止纯评分器读取可变世界。关系含尚有效的效果，但不改写基线。
3. **行为专用评分**：每类行为有自己的因素、方向、门槛；整数运算，输出总分、阈值、各项贡献。
4. **选择**：优先显式职责；合法候选按分数降序、人物 ID 升序。同分不依赖字典顺序。允许等待/休息，不强迫每天社交。
5. **提交**：单线程按固定顺序复核和扣费，再记录结果。失败不得宣称成功，决策记录不是事件记忆。
6. **反馈**：本势力人物显示最近决策依据；不能因此暴露敌方决策。提示说明游戏规则，不声称读懂真实历史人物。

首版没有随机决策。后续需要不确定性时使用存档内确定性随机流，并区分“判断误差”与“执行随机”；不能每帧重掷至成功。

## 三、行为目录及设计方向

| 行为 | 主要动机/输入 | 执行约束与后续扩展 |
| --- | --- | --- |
| 交谈 | 归属、温和、重义、心情、亲疏/信任、近期重复会面 | 同地点及冷却；魅力影响效果；后续补谈话主题与双方意愿 |
| 赠礼 | 物质/表达善意、收礼人欲望、关系 | 先支付个人资源；保留递减；后续加入物品类别、拒礼与贿赂风险 |
| 婚约回应 | 自愿亲近、信任、重义、慎重、心情、近期拒绝经历 | 成年/非近亲/无在世配偶为硬门槛；真人明确同意；不自动产生联盟 |
| 忠诚演化 | 对当主的关系、信任、重义、野心和心情 | 周结算、小步有界；后续接入赏罚、公平待遇和价值冲突 |
| 叛离 | 不满、低忠诚、野心与对既有纽带的重视 | 先预警、滞回避免反复跳变；30 日后仍需现实出路，禁止携城兵偷换归属 |
| 解围 | 职责、勇气、慎重、对被救者的关系、军事判断质量 | 使用可见目标、正常路径与战斗；性格调风险容忍而非无视绝对兵力底线 |
| 任务执行 | 职责、能力/熟练度、健康、命令成本 | 当前任务优先；后续按任务种类区分效率、合理异议、拖延、拒令 |
| 外交与交易 | 立场、可信承诺、利益判断、谈判能力 | 先接入可知报价/条约，不允许读取隐藏价格或未来结果 |
| 战斗与撤退 | 生存、职责、勇气、慎重、统率与军略 | 保留现有战斗计算；未来统一风险表达，避免同一性格重复加权 |

## 四、记忆与关系演化

- 短期记忆是有限的生活经历窗口：交谈重复降低近期社交新鲜感；婚约被拒在 60 日内降低再次接受该对象的倾向。按年龄衰减，未来日期和过期记忆不参与；单类影响有上限。
- 已经发生的赠礼、结婚等亲疏变化只发生一次。记忆不每日重放；不把普通谈话堆成无限信任。
- 长期事件（救命、杀亲、背誓、重大赏罚）后续使用单独的有限“关键记忆”，带事件源 ID、影响维度、强度与衰减策略，不能依靠最近 64 条审计列表永久保存。
- 亲疏、信任、敬重、畏惧、恩怨的完整多轴扩展为后续，不将旧亲疏一键复制成所有轴。新增轴默认 0，身份关系保留。
- 性格本轮不自动漂移。未来重大事件只能小幅、低频、有上限调整；平时情绪变化优先，不因一次礼物改变价值观。

## 五、职责、命令与玩家控制

明确区分“玩家决定角色做什么”和“NPC 自主决定”。玩家当主的社交与婚约不被 AI 代办；离线联机仍保护婚约同意。已有募兵、外交、行军或休息状态不被自由社交抢占。

未来命令分为建议、职责令、强制令，但本轮不新增随意违令。违令需合法原因、可见预警、行为代价和申诉/撤回流程；任务失败不得自动等价为不忠。战争危急时可提高职责权重，但不能强迫真人接受婚姻。

## 六、多核、内存与确定性

- 评分函数只有不可变标量输入。社交候选评分接入 MapOrdered：达到每工作批次门槛才并行，其余顺序计算，不为每人物启动一个线程。
- 提交仍按人物 ID 排序；当日较早互动可改变较晚人物的观测，这是明确的顺序语义。并行度不改变结果，不同时写双方关系。
- 当日按地点建立社交候选索引，避免每个 NPC 扫描整个世界；只纳入空闲健康候选。迁移后复核地点与势力，防止旧索引误用。
- 保留 64 条社交记忆；决策日志最多保留每人物 5 类最近记录，不保存所有候选得分或永久逐日日志。输入分数有界，采用整数，不依赖墙上时间。
- 验收需包括不同输入顺序、重复日结算、JSON 读档续玩、并行与串行一致、多人 DTO 隔离，以及不同性格在同一局势下的反事实测试。

## 七、首批落地范围

本批实现：统一不可变评分输入、可解释贡献、社交/婚约/忠诚/叛离评分、解围风险阈值、本势力最近决策显示、记忆近期影响、索引候选与受控并行评分。

不宣称全部人物行为已经统一：一般战斗、外交/经济与任务评分仍使用现有规则；长期目标计划器、关系新增轴、关键事件总线、性格成长、政治婚姻、生育继承、带兵叛乱均需后续批次。本设计覆盖这些扩展接口，但不以文档存在冒充功能落地。
